# Week 3: F1 grid position analysis

How well does starting grid position predict finishing position in Formula 1, and has that changed from the 1950s to today?

| File | What it is |
| --- | --- |
| `analysis_plan.md` | Steps 1 to 4: questions, definitions, cleaning plan, feasibility |
| `f1_grid_analysis.ipynb` | Step 5: the analysis, with checkpoints, charts and findings |
| `data/` | `results`, `races`, `status`, `circuits` CSVs from [Arths17/f1-dataset](https://github.com/Arths17/f1-dataset) (CC0) |

Run: `pip install pandas matplotlib`, then open the notebook and run all cells.
